8 REFERENSI

Cara website membaca angka fatigue

Skor fatigue diambil dari data Health Hub tanpa dihitung ulang. Selisih dibandingkan dengan rata-rata data yang tersedia pada 7 hari kalender sebelumnya, tanpa memasukkan hari terpilih. Tidur, langkah, dan detak jantung istirahat memberi konteks deskriptif, bukan prediksi penyebab kelelahan.

Rentang skor dan nama instrumen wajib berasal dari sumber. Website tidak menetapkan kategori ringan, sedang, atau berat. Artikel menggunakan metode yang beragam, termasuk FAS, IFRC dan reaction timer; nilainya tidak dapat disamakan dengan skor wearable. Studi deskriptif juga tidak membuktikan hubungan signifikan atau sebab-akibat.

Referensi berikut mengikuti ringkasan yang diberikan. Artikel #3 dan #4 memiliki tautan penerbit yang ditemukan; detail artikel lainnya belum diverifikasi terhadap naskah lengkap. Klaim “7 dari 8 signifikan” tidak dipakai karena desain dan luaran penelitian berbeda.

HEALTH HUB API

Terhubung ke data server

Health Hub mengirim data ke POST /api/v1/records. Masukkan API key profil Anda untuk membaca riwayat dari server ini. Dashboard memeriksa pembaruan setiap 30 detik selama tab aktif.

API belum terhubung.

API key hanya disimpan dalam memori tab ini. Data server tidak disalin ke localStorage. Setelah halaman dimuat ulang, hubungkan kembali.

Impor dari Health Hub

Impor berkas untuk analisis lokal tanpa mengirimnya ke server. Untuk menerima kiriman langsung dari aplikasi Health Hub, hubungkan API di atas.

Alur data yang transparan

Zepp → Health Connect → Health Hub → API / JSON

Impor agregat harian dari aplikasi, bukan input angka manual. sleep_minutes mewakili durasi tidur malam sebelum tanggal data. Penggabungan sesi dan penghapusan duplikasi dilakukan di aplikasi sumber.

{
  "source": "Health Hub",
  "fatigue_scale": {
    "name": "Nama indeks dari sumber",
    "min": 0, "max": 100
  },
  "records": [{
    "date": "2026-09-07",
    "fatigue": 42,
    "sleep_minutes": 420,
    "steps": 6800,
    "resting_hr": 64
  }]
}

Rentang 0–100 hanya contoh, bukan asumsi tentang skala aplikasi. Gunakan null untuk nilai yang belum tersedia.

Pilihan penyimpanan yang jelas

Impor berkas disimpan lokal di browser. Kiriman API dari aplikasi disimpan di database server per profil. Menghapus data lokal tidak menghapus database server.
